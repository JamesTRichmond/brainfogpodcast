# Late Night Brain Fog

James Richmond's late-night show. Two people talking. About an hour.

Site for [brainfogpodcast.com](https://brainfogpodcast.com).

## Run

```bash
npm install
npm run dev
```

Preview is `http://127.0.0.1:8080/`.

## Host

Audio files live on Transistor. This repo is the site. Vercel builds it. Squarespace only holds the domain name.

## Honest

Nothing is recorded yet. No fake tape. Subscribe buttons stay off until an hour is actually up.
